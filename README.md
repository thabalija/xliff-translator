# Xliff Translator

Open-source app for translating XLIFF 2.0 files generated by [Angular i18n](https://angular.dev/guide/i18n).

Published at [xliff-translator.firebaseapp.com](https://xliff-translator.firebaseapp.com/).

## Requirements

- Node.js 22.22.3+ (see `.nvmrc`)
- [pnpm](https://pnpm.io/) 11.22.0+ (Corepack: `corepack enable && corepack prepare pnpm@11.22.0 --activate`)

This workspace refuses package versions published fewer than **3 days** ago (`minimumReleaseAge: 4320` in `pnpm-workspace.yaml`).

## Scripts

```sh
pnpm install
pnpm start          # http://localhost:4200/
pnpm test
pnpm lint
pnpm build
pnpm e2e
```

Sample files are linked in the app footer (`/docs/test_file.en.xml`).

## Features

- Upload an untranslated or already translated XLIFF 2.0 file
- Create multiple target translations
- Edit source units and apply them to existing translations
- Download translated files
- Offline storage in `localStorage` (known keys only)
